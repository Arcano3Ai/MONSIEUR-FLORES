# MONSIEUR FLORES — Boutique Floral Digital & Experiencia de Lujo

> **“El arte de decirlo con flores. Hay cosas que las palabras no saben decir.”**  
> *Dime qué quieres decir y Monsieur Flores encontrará la manera de expresarlo con flores.*

---

## 🌹 Resumen Ejecutivo de la Solución
**Monsieur Flores** es una experiencia e-commerce de alta floristería concebida no como una tienda genérica de catálogo, sino como una **boutique de emociones y regalos guiada por un anfitrión**: Monsieur Flores, maestro florista de carácter refinado, cálido y teatral.

La arquitectura implementa al 100% las 17 secciones del Home, la jerarquía emocional, la interacción Mobile-First y los flujos preparados para checkout visual y conciliación floral.

---

13. **Testimonios 5 Estrellas:**

14. **Instagram Social Proof (@monsieurflores):**
    - Grid visual con métricas de interacción.
15. **Journal de Monsieur (SEO & Guía Floral):**
    - Artículos editoriales sobre significado de rosas, protocolo para pedir perdón y numerología de tallos.
16. **CTA Final:**
    - *“¿A quién le mandarías flores hoy? Monsieur se encarga del resto.”*
17. **Footer Integral:**
    - Enlaces corporativos, políticas, redes y formulario de suscripción a las *Cartas de Monsieur*.
18. **Mobile Experience:**
    - Barra de navegación inferior fija (`⌂ Inicio | ♡ Favoritos | 🔎 Buscar | 🛒 Carrito | 🌹 Monsieur`).

19. **Drawers y Modales:**
    - **Drawer de Carrito:** Con cálculo de subtotal, desglose de complementos y actualización reactiva.
    - **Drawer de Favoritos:** Guardado en `localStorage`.
    - **Modal de Detalle de Producto:** Con selector dinámico de tamaños (Clásico, Magno, Imperial) y detalles botánicos.
    - **Modal de Checkout Visual (5 pasos):** Datos comprador → Destinatario → Momento y franja horaria → Revisión de dedicatoria → Pago cifrado → **Pantalla de Tracking Animado de Pedido** (*"Monsieur está preparando tu arreglo"*).

## 🛠️ Tecnologías y Arquitectura

- **Build Tool:** Vite 6 (HMR instantáneo y empaquetado optimizado).
- **Core:** Vanilla JavaScript ES Modules (Clean Architecture, arquitectura por eventos pub/sub, desacoplada y sin dependencias pesadas).
- **Estilos:** Vanilla CSS con CSS Custom Properties (Design Tokens), arquitectura modular BEM-friendly, tipografías `Cormorant Garamond` y `Playfair Display`.
- **Persistencia Local:** `localStorage` para Carrito, Favoritos y preferencias.
- **Assets Gráficos:** Imágenes cinematográficas exclusivas generadas con IA guardadas localmente en `/public/images/`.

## 🚀 Cómo Ejecutar el Proyecto

```bash
# 1. Instalar dependencias (si no se ha hecho previamente)
npm install

# 2. Iniciar servidor de desarrollo local
npm run dev

# 3. Compilar para producción
npm run build

# 4. Previsualizar compilación de producción
npm run preview
```
El servidor abrirá la aplicación en `http://localhost:3000` (o el siguiente puerto disponible).
